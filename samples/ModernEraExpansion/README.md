# Modern Era Expansion — functional v1 sample

Adds Modern Supply Depot (ID 900001), not a replacement: build with a villager under Mods. Costs 100 wood + 50 stone, takes 40 simulation seconds, has 900 HP, adds 10 population capacity and accepts four resources. Uses an original transparent 256×192 sprite; construction stages come from the user’s imported game data. It can be built, damaged, destroyed and saved. No original assets are distributed.

Modern Barracks, Military Factory, Power Plant, Radar Station, Advanced Research Center, modern units and technologies are roadmap items. v1 does not register custom units, technologies, civilizations or scripts.
